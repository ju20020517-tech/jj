# 🍃 두근두근 섬 생활

동물의 숲 분위기의 귀여운 섬 생활 게임입니다. 라이브러리 없이 **바닐라 JS + Canvas**로 만들었습니다.

## 실행
`index.html`을 브라우저로 열면 바로 플레이할 수 있어요. 설치나 빌드는 필요 없습니다.

## 조작
| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 (Shift: 달리기) |
| Space / E | 행동: 나무 흔들기, 줍기, 대화, 팔기 |
| Q | 선택한 아이템 심기 / 내려놓기 |
| 1 ~ 0 | 가방 칸 선택 |

모바일에서는 화면 위에 방향 패드와 `행동` / `심기` 버튼이 나타납니다.

## 할 수 있는 것
- 🌳 나무를 흔들어 과일 따기 (90초 뒤 다시 열림)
- 🌱 과일을 심으면 2분 뒤 나무로 자람 · 🌷 꽃 심기 / 꺾기
- 🌿 잡초 뽑기, 🐚 바닷가 조개 줍기, 🪨 바위 두드려 돌멩이 얻기
- 📦 상점 상자에 팔아서 벨 모으기
- 🐱 주민 "뭉치"와 대화하기 (과일을 들고 말을 걸면 선물을 줄 수 있음)
- 📝 할 일 목록: 추가 / 삭제 / 완료 체크, 섬 미션은 자동으로 진행되고 보상 지급
- 🎨 이름, 섬 이름, 옷 색깔, 머리 색깔 꾸미기
- 🌇 실제 시간에 맞춰 낮 → 노을 → 밤(반딧불이)으로 바뀜

## 저장 (localStorage)
`cozy-island-save-v1` 키에 자동 저장됩니다.
- 할 일 추가/삭제/완료, 아이템 줍기/심기/팔기, 캐릭터 설정을 바꿀 때마다 즉시 저장
- 캐릭터 위치는 이동 중 1.5초마다 저장하고, 페이지를 닫거나 새로고침할 때도 저장
- 섬 지형은 시드로 만들어져서 새로고침해도 같은 섬이 유지됨
- `캐릭터 → 섬 처음부터 다시 시작`으로 저장 데이터를 초기화할 수 있음

## 파일 구성
- `index.html` — 화면 구조
- `style.css` — 파스텔 톤 스타일, 모바일 대응
- `game.js` — 맵 생성, 캐릭터·오브젝트 그리기, 게임 로직, 저장/불러오기
