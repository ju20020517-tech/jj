# 🏝️ 친구모아 아일랜드

주민들의 **우정 · 짝사랑 · 연애 · 질투 · 권태기 · 결혼 · 육아 · 유전**을 관찰하고 참견하는 3D 섬 생활 시뮬레이션이에요.
바닐라 JS와 Three.js(`vendor/`에 포함)로 만들었고, 모든 모델·텍스처·음악을 코드로 생성해요.

## 실행
`index.html`을 브라우저로 열면 돼요. 설치, 빌드, 서버가 필요 없어요. (WebGL 필요)
- `creator.html`: 캐릭터 만들기. 여기서 만든 캐릭터를 나 또는 주민으로 데려올 수 있어요.
- `classic.html`: 이전 버전(두근두근 섬 생활)

## 핵심
- 주민 성격은 **[메인 성격 10] + [서브 행동 8] + [대화 태도 8] + [특이 취향 10]**을 무작위로 조합해요. 조합에서 속도, 활동 범위, 휴식 시간, 행동 가중치가 계산돼요.
- 5대 구역(중앙 코어 · 북쪽 고지대 · 서쪽 주거 · 동쪽 번화가 · 남쪽 해안)에서 주민들이 24시간 스케줄대로 출근하고, 놀고, 연애해요.
- 주민 머리 위에 **고민 풍선(!)**이 뜨면 말을 걸어 코칭해 주세요. 분홍은 짝사랑, 붉은색은 질투, 보라색은 권태기예요.
- 🏢 시티 타워 20개 창문을 관찰하고, 창문을 눌러 방 안으로 줌인할 수 있어요. 2D 창문 뷰와 3D 오비트를 바꿀 수 있고, 방 꾸미기·DIY 무늬·인테리어 코드도 있어요.
- ✨ 신의 툴: 속마음 돋보기, 방 테마 즉시 교체, 운명의 불꽃, 꿈속 침투 렌즈(미니게임)
- 💬 **미연시 대화창**: 주민의 3D 스탠딩 초상화가 대사에 맞춰 표정(기쁨·설렘·슬픔·화남·놀람)을 바꾸고, 대사는 타자기처럼 흘러나와요. 대화하는 동안 주민은 그 자리에 가만히 서서 나를 바라봐요.
- 🗺️ **지도 이동**: 지도(M)에서 장소나 주민을 골라 ✨ 바로 가기(순간 이동) · 🚪 바로 들어가기 · 🚶 걸어서 가기(자동 길찾기) · 📍 목적지 표시
- 🌳 **동물의 숲 풍 그래픽**: 손그림 텍스처(잔디·흙길·지층 절벽·비늘 지붕·판자·벽돌·돌·통나무), 바람에 흔들리는 3D 풀, 3D 꽃(튤립·코스모스·팬지·국화), 몽글몽글 나무와 과일, 둥근 덤불. 모든 건물을 박공 지붕·덧창 창문·화분·줄무늬 차양·굴뚝·현관 포치가 있는 모양으로 새로 만들었어요 (밤엔 창문에 불이 켜져요)
- 🎨 **동적 방 분위기**: 메인 성격이 벽지 색·조명을, 특이 취향이 벽지 무늬·파티클·배경 소리를 정해요. 취향에 딱 맞으면 공중부양 댄스, 전혀 안 맞으면 눈을 가리고 구석에 웅크려요
- 🏠 **주민 방 레퍼런스 스타일 5종**: 🌿 초록 코티지(로프트 침대·깅엄 소파·티피 텐트·쇼지 창) / 🐠 아쿠아리움 밤 방(수족관 벽·빛나는 덩굴·패치워크 침대·지구 러그·용암등) / 🍒 핑크 로맨틱(핑크 판벽·장미 벽지·체리 침대·에그 체어) / 🏆 스포티 개러지(트로피장·레이싱카 침대·벤치 프레스·전자 작업대) / 🏙️ 콘크리트 로프트(도시 통창·블랙 가죽 소파·CRT TV·기타&앰프). 성격 4단계 조합으로 가장 잘 맞는 스타일이 자동 선택되고, 관찰 패널에서 스타일을 바꿔볼 수 있어요.
- 🐼 **다양한 주민**: 32종(사람 + 동물 31종: 판다·호랑이·늑대·젖소·원숭이·병아리·수달·북극곰·아기양·사자·고슴도치·시바견·알파카·부엉이·물범 등). 종마다 체구가 달라요(햄스터·병아리는 작고 곰·북극곰·사자는 커요). 같은 종도 털색이 겹치지 않게 변주되고, 성격 4단계(L1~L4)에 맞춰 옷·모자·안경·소품·표정이 랜덤으로 입혀져요. 눈은 먼작귀처럼 까만 콩 눈 + 볼 빗금.
- 🏠 **성격 조합별 방**: 메인 성격(색감·벽지·바닥·대표 가구) + 서브 행동(반듯/어질러짐/아늑/미니멀/사교 배치) + 대화 태도(조명·음악) + 특이 취향(취미 가구·러그 색)
- 🛋️ **가구 상호작용**: 집·주민 방·가게의 가구에서 E(여러 개면 R)로 눕기·요리·TV·노래방·운동 등. 놀이 센터(네온 스파크)는 오락기·인형뽑기·볼링·펌프를 타이밍 미니게임으로, 놀이터는 미끄럼틀·그네·시소·모래성
- 🚶 **동행**: 친한 친구는 '동행 산책', 일반 친구는 '근처 건물 같이 구경'으로 최대 4명과 건물에 함께 들어가고, 내가 가구를 쓰면 옆에서 같이 놀아요
- 🖐️ **가구 옮기기**: 방 꾸미기에서 가구를 잡고 끌기 (벽걸이는 벽에 착), Q/R 회전 · 방향키 미세 이동 · Delete 회수
- 🖼️ **내 이미지 붙이기**: 포스터·가로 포스터·대형 캔버스·액자·탁상 액자에 내 사진/그림 파일을 붙여요 (섬 전체 30장까지)
- 📌 **친절한 퀘스트**: 단계별 할 일, 보상, 남은 시간, 방향 화살표가 화면에 뜨고, ⭐ 빛기둥이 목적지를 알려줘요.

기획서의 각 항목이 어디에 구현됐는지는 **[SPEC_CHECKLIST.md](SPEC_CHECKLIST.md)**에 정리돼 있어요.

## 파일 구성 (`js/fm/`)
- `data.js`: 성격 레이어, 행동, 관계 단계, 테마, 아이템 / `map.js`: 장소, 도로 그래프, 지하철 / `terrain.js`: 지형 높이, 물, 이동 판정
- `furniture.js`, `interiors.js`: 가구 카탈로그, 실내 공간 / `lines.js`: 말투별 대사
- `sim-core.js`: 시간, 주민 생성, 스탯 융합, 길 찾기, 스케줄, 행동 두뇌, 장면 엔진
- `sim-social.js`: 친구, 짝사랑, 연애, 질투, 권태기, 결혼, 육아, 유전, 퀘스트, 플레이어 대화
- `sim-events.js`: 구역별 엉뚱 이벤트, 뉴스·랭킹, 경제, 날씨, 병원, 방 테마 반응
- `actex.js`: 동물의 숲 풍 캔버스 텍스처와 건물 부품 키트 / `acbld.js`: 모든 건물 외관
- `play.js`: 플레이어 가구·놀이 시설 사용, 타이밍 미니게임
- `guide.js`: 지도 이동(순간 이동·자동 길찾기), 목적지 표시, 퀘스트 단계 안내 / `portrait.js`: 미연시 대화창 3D 초상화·표정
- `props.js`, `world3d.js`, `chars3d.js`, `interior3d.js`, `anim.js`: 3D 렌더링 / `audio.js`: 합성 BGM·효과음 / `ui.js`, `main.js`: 화면과 조작

# (이전 버전) 두근두근 섬 생활 3D — `classic.html`

동물의 숲 분위기의 3D 섬 생활 게임입니다. **바닐라 JS**로 만들었고, 3D 렌더링에만 [Three.js](https://threejs.org) (r149, `vendor/`에 포함)를 사용합니다.
모델과 텍스처는 이미지 파일 없이 전부 코드(기본 도형 + Canvas)로 만들었습니다.

둥글고 귀여운 느낌을 위해 모서리가 둥근 상자, 캡슐, 회전체(lathe), 매끈한 구를 조합하고,
모든 재질에 펠트 같은 부드러운 림 라이트와 부드러운 그림자(VSM)를 적용했습니다.
캐릭터는 큰 머리의 2등신이고, 걸을 때 통통 튀는 스쿼시&스트레치 애니메이션이 있어요.

## 실행
`classic.html`을 브라우저로 열면 바로 플레이할 수 있어요. 설치·빌드·서버가 필요 없습니다. (WebGL 지원 브라우저 필요)

## 조작
| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 (Shift: 달리기) |
| Space / E | 행동: 나무 흔들기, 줍기, 대화, 팔기, 가구 선택 |
| Q | 선택한 아이템 심기 / 내려놓기 |
| 1 ~ 0 | 가방 칸 선택 |
| 마우스 휠, ＋/－ | 확대 / 축소 |
| (집 안) R / X / Esc | 가구 회전 / 회수 / 취소 |

모바일: 화면을 끌면 조이스틱이 나오고, 오른쪽 아래 `행동`·`심기`·`달리기` 버튼을 사용해요.

## 섬
- 언덕 위에서 떨어지는 **폭포**와 강, 나무 **다리**, 언덕으로 오르는 **비탈길**
- 🌳 과일나무 흔들기 (90초 뒤 다시 열림) · 🌱 과일을 심으면 2분 뒤 나무로 자람
- 🌼 꽃 심기/꺾기, 🌿 잡초 뽑기, 🐚 조개 줍기, 🪨 바위에서 돌멩이 얻기
- 📦 상점 상자에 팔아서 벨 모으기
- 🐾 오리지널 주민 5명 (고양이 모카, 곰 보리, 오리 덕배, 햄스터 콩이, 강아지 몽실)
  - 섬을 돌아다니고, 말을 걸면 대답하고, 과일을 선물하면 친해져요
- 🌇 실제 시간에 맞춰 낮 → 노을 → 밤 (가로등, 창문 불빛, 반딧불이)

## 집 꾸미기
문으로 걸어가면 집 안으로 들어가요. 민트색 레트로 거실이 기본으로 꾸며져 있어요.
- `가구` 탭에서 17종 가구를 골라 벨로 구입해 배치
- 놓인 가구를 클릭하거나 앞에서 Space → 회전 / 옮기기 / 회수(벨 환불)

## 🎨 캐릭터 만들기 (`creator.html`)
동물의 숲 같은 둥글둥글한 주민을 직접 만드는 도구예요. 게임 위쪽의 `🎨 캐릭터 만들기` 링크나 `creator.html`로 열어요.
- **종 32가지**: 사람, 고양이, 강아지, 곰, 너구리, 토끼, 햄스터, 생쥐, 다람쥐, 오리, 돼지, 코알라, 양, 개구리, 펭귄, 여우, 사슴, 판다, 호랑이, 늑대, 젖소, 원숭이, 병아리, 수달, 북극곰, 아기양, 사자, 고슴도치, 시바견, 알파카, 부엉이, 물범
  (종마다 귀·주둥이·꼬리 모양이 달라요)
- **얼굴**: 눈 8종, 눈동자 색, 눈썹 6종, 입 8종, 볼터치, 얼굴 무늬(줄무늬·마스크·얼룩·주근깨 등)
- **털색**: 몸/주둥이/귀 안쪽/무늬/부리 색 (팔레트 + 직접 색 고르기)
- **머리(사람)**: 피부색, 머리 모양 6종, 머리 색
- **옷**: 윗옷 7종(티셔츠·스웨터·후드티·알로하·조끼·원피스·앞치마), 무늬 10종, 아래옷 4종, 신발
- **소품**: 모자·머리장식 8종, 안경 3종, 액세서리 4종, 사슴뿔
- 미리보기: 드래그로 회전, 휠 확대, 포즈(서기·걷기·인사·깡충·수다), 자동 회전
- 🎲 랜덤 만들기, 📷 주민증 사진(PNG) 저장, 추천 스타일로 시작하기
- **도감**: 저장·수정·삭제 (localStorage `cozy-island-creator-v1`), JSON 내보내기/가져오기
  - `🙋 내 캐릭터` → 섬에서 그 캐릭터로 플레이
  - `🏝️ 초대` → 섬에 주민으로 등장 (최대 8명, 말버릇으로 대화)

## 할 일 목록
추가 / 삭제 / 완료 체크 · 필터(전체/진행 중/완료) · "섬 미션"은 플레이하면 자동으로 진행되고 보상 500벨

## 저장 (localStorage)
`cozy-island-3d-v1` 키에 자동 저장됩니다.
- 할 일 추가·삭제·완료, 아이템 줍기·심기·팔기, 가구 배치·회수, 캐릭터 꾸미기 때마다 즉시 저장
- 캐릭터 위치(섬/집 안)는 이동 중 1.5초마다, 그리고 페이지를 닫거나 새로고침할 때 저장
- 섬 지형은 시드로 다시 만들어져서 새로고침해도 같은 섬
- 예전 2D 버전 저장 데이터가 있으면 할 일·가방·벨·이름을 처음 한 번 이어받음
- `나 → 섬 처음부터 다시 시작`으로 초기화

테스트용: 주소 뒤에 `?hour=21`을 붙이면 원하는 시간대(밤)를 볼 수 있어요.

- `js/textures.js` — Canvas로 그리는 텍스처 (잔디, 물, 벽지, 옷 무늬, 얼굴 등)
- `js/models.js` — 나무, 꽃, 집, 가구 3D 모델
- `js/character.js` — 캐릭터 빌더(종·얼굴·옷·소품)와 애니메이션 — 게임과 캐릭터 만들기가 함께 사용
- `creator.html`, `creator.css`, `js/creator.js` — 캐릭터 만들기 도구
- `js/world.js` — 섬 지형 생성, 높이/충돌, 물·폭포
- `js/game.js` — 게임 로직, 카메라, 입력, 저장/불러오기, UI
- `vendor/three.min.js` — Three.js (MIT 라이선스, `vendor/LICENSE-three.txt`)
