# 🍃 두근두근 섬 생활 3D

동물의 숲 분위기의 3D 섬 생활 게임입니다. **바닐라 JS**로 만들었고, 3D 렌더링에만 [Three.js](https://threejs.org) (r149, `vendor/`에 포함)를 사용합니다.
모델과 텍스처는 이미지 파일 없이 전부 코드(기본 도형 + Canvas)로 만들었습니다.

## 실행
`index.html`을 브라우저로 열면 바로 플레이할 수 있어요. 설치·빌드·서버가 필요 없습니다. (WebGL 지원 브라우저 필요)

## 조작
| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 (Shift: 달리기) |
| Space / E | 행동: 나무 흔들기, 줍기, 대화, 팔기, 가구 선택 |
| Q | 선택한 아이템 심기 / 내려놓기 |
| 1 ~ 0 | 가방 칸 선택 |
| 마우스 휠, ＋/－ | 확대 / 축소 |
| (집 안) R / X / Esc | 가구 회전 / 회수 / 취소 |

모바일: 화면을 끌면 조이스틱이 나오고, 오른쪽 아래 `행동`·`심기`·`달리기` 버튼을 사용해요.

## 섬
- 언덕 위에서 떨어지는 **폭포**와 강, 나무 **다리**, 언덕으로 오르는 **비탈길**
- 🌳 과일나무 흔들기 (90초 뒤 다시 열림) · 🌱 과일을 심으면 2분 뒤 나무로 자람
- 🌼 꽃 심기/꺾기, 🌿 잡초 뽑기, 🐚 조개 줍기, 🪨 바위에서 돌멩이 얻기
- 📦 상점 상자에 팔아서 벨 모으기
- 🐾 오리지널 주민 5명 (고양이 모카, 곰 보리, 오리 덕배, 햄스터 콩이, 강아지 몽실)
  - 섬을 돌아다니고, 말을 걸면 대답하고, 과일을 선물하면 친해져요
- 🌇 실제 시간에 맞춰 낮 → 노을 → 밤 (가로등, 창문 불빛, 반딧불이)

## 집 꾸미기
문으로 걸어가면 집 안으로 들어가요. 민트색 레트로 거실이 기본으로 꾸며져 있어요.
- `가구` 탭에서 17종 가구를 골라 벨로 구입해 배치
- 놓인 가구를 클릭하거나 앞에서 Space → 회전 / 옮기기 / 회수(벨 환불)

## 할 일 목록
추가 / 삭제 / 완료 체크 · 필터(전체/진행 중/완료) · "섬 미션"은 플레이하면 자동으로 진행되고 보상 500벨

## 저장 (localStorage)
`cozy-island-3d-v1` 키에 자동 저장됩니다.
- 할 일 추가·삭제·완료, 아이템 줍기·심기·팔기, 가구 배치·회수, 캐릭터 꾸미기 때마다 즉시 저장
- 캐릭터 위치(섬/집 안)는 이동 중 1.5초마다, 그리고 페이지를 닫거나 새로고침할 때 저장
- 섬 지형은 시드로 다시 만들어져서 새로고침해도 같은 섬
- 예전 2D 버전 저장 데이터가 있으면 할 일·가방·벨·이름을 처음 한 번 이어받음
- `나 → 섬 처음부터 다시 시작`으로 초기화

테스트용: 주소 뒤에 `?hour=21`을 붙이면 원하는 시간대(밤)를 볼 수 있어요.

## 파일 구성
- `index.html`, `style.css` — 화면 구성과 UI
- `js/data.js` — 아이템, 가구, 주민, 상수
- `js/textures.js` — Canvas로 그리는 텍스처 (잔디, 물, 벽지, 옷 무늬, 얼굴 등)
- `js/models.js` — 캐릭터, 나무, 꽃, 집, 가구 3D 모델과 애니메이션
- `js/world.js` — 섬 지형 생성, 높이/충돌, 물·폭포
- `js/game.js` — 게임 로직, 카메라, 입력, 저장/불러오기, UI
- `vendor/three.min.js` — Three.js (MIT 라이선스, `vendor/LICENSE-three.txt`)
